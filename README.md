### What I've been building

- **SQL Convention Agent** — encodes a codebase's unwritten SQL conventions (audit logging, naming, trigger generation) so a Copilot agent applies them automatically. Cut routine scripts from ~20 minutes to under 10; a 30-40 hour complex FK-backfill estimate to about half.
- **ADA/WCAG Compliance Agent** — reviews code file-by-file, converts to semantic HTML, and proposes accessibility fixes with the specific WCAG rule each one satisfies; now generates per-file SVN patches and scans an entire codebase on its own. Manual audits run 50–60 hours per system across 50+ systems needing it — full automation is projected to cut that to about 5 hours, validated so far on folder-scoped tests.
- **MCP Server Infrastructure** — built the company's first MCP server after a manual client-import process (40–50 hours of fiscal-manager work per cycle) needed automating, then expanded into two dev-workflow tools: one that answers schema/convention questions directly against our database, one that uses SVN to answer codebase and commit questions. Led a technical meeting with AWS engineers to scope hosting via AgentCore, Bedrock, and Lambda.
- **EMR UI/UX Overhaul** — architected a reusable, tokenized CSS system to modernize a 30-year-old product UI and, after a senior-dev demo, rebuilt an internal site's frontend in 3 days. Now leading a formal design system (2 junior developers, 2-week timeline) turning that work into documented, reusable components.
- **AI-Assisted Trading Indicators** — a custom Claude Skill for Pine Script development (this repo: [AI-Skill-Vault](https://github.com/jescamilla1/AI-Skill-Vault)) that catches likely bugs before they ship. Built a dynamic support/resistance tool used by a 3,000+ member Discord community, plus a harmonic-pattern detector built from scratch.
- **[soccer-model-vs-market](https://github.com/jescamilla1/soccer-model-vs-market)** — a from-scratch Elo/Poisson/logistic-regression prediction stack for the 2026 World Cup, backtested against 45,000+ historical matches, compared against Kalshi's market price.
